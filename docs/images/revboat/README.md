# 版舟界面截图

本目录用于项目首页及使用手册，展示 RevBoat 0.6.6 定制版的实际前端。

- 截图取自生产前端，通过测试脚本注入隔离的演示数据。
- 项目名称、路径、服务器、账号、提交历史和代码均为示例，不包含用户实际仓库数据。
- `workspace.png`：本地变更与差异预览。
- `history.png`：提交历史、提交详情与内嵌差异。
- `checkout.png`：连接测试、远程目录浏览与检出选项。
- `authentication.png`：图形化认证弹窗。
- `workspaces.png`：工作区切换与完整路径。
- `diff.png`：历史文件完整对比。
- `account.png`：SVN 账号管理。
- `logo.png`：帆舟应用图标，由 `src-tauri/icons/revboat.svg` 生成。

截图由 `scripts/check-desktop-ui.cjs` 和 `scripts/check-diff-account-ui.cjs` 的演示流程生成，按最长边 1440 像素缩放后纳入仓库。安装包不包含演示数据或模拟接口。
