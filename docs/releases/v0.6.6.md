# 版舟 RevBoat v0.6.6

版舟是基于 OrcaSVN v0.6.6 定制的 SVN 桌面客户端。本次为 RevBoat 的首次正式发布。

## 界面与工作区

- 全新侧边栏、工作区、本地变更、提交历史、检出和认证界面。
- 工作区切换直接展示目录路径，方便管理多个 SVN 工作副本。
- 新的版舟名称、帆船图标及配图用户手册。

## SVN 登录与账号

- 远程操作需要认证时，通过应用内窗口输入账号密码，无需先在终端登录。
- macOS 认证成功后保存到系统钥匙串，重启后可再次使用。
- 在“设置 → SVN 账号”验证并修改客户端凭据；新凭据验证失败时保留旧凭据。

## 文件对比与稳定性

- 修复提交历史中修改、删除及特殊字符路径的文件对比。
- 补充空差异、二进制文件和错误状态提示。
- 修复 Windows 文件名兼容性回归测试，并通过 Linux、Windows CI 检查。

## 下载与使用限制

- Windows：提供 NSIS EXE 和 MSI，内置私有 UTF-8 SVN 运行时。
- macOS：提供 Apple Silicon 安装包；本次 GitHub 自动构建包需另行安装 SVN 命令行工具。它与之前本地生成、内置 SVN 的 macOS 26+ 安装包不同。
- Linux：提供 x64 安装包，需另行安装 SVN 命令行工具。
- 尚未配置 Apple 公证及 Windows 代码签名。
- macOS 支持钥匙串保存凭据；Windows、Linux 目前仅保留会话凭据。
- 尚未提供完整的 Switch、Merge、Resolve 图形操作入口，也不支持 Office/PDF 内容对比或左右双栏对比。
- 自动构建通过不代表所有系统上的安装和实际 SVN 操作均已完成验收。
