# 本地 UI 改版（2026-11-25）

基于 OrcaSVN v0.6.6 及此前的 GUI 认证修复，参考用户提供的四张 PNG 原型调整实际 Vue/Tauri 应用。本地改版未发布到上游。

## 已实现

- 单侧栏、仓库切换器、紧凑工具栏、版本与本地状态栏。原有工作区收藏、排序、备注、移除等功能仍在仓库切换窗口内。
- 提交历史采用日期分组、深蓝选中行和右侧详情；支持按作者、关键词及日期筛选，右侧查看文件差异，保留独立完整差异页与分页。
- 本地变更采用文件列表和差异分栏，支持文件勾选、搜索和提交说明草稿；“检查并提交”将选中项及说明带入已有提交检查页面，确认后才发布。冲突文件不可直接勾选提交。
- 检出页增加真实连接测试、远程目录浏览、版本选择、检出深度、忽略外部引用和完成后切换工作副本选项。双击或按 Enter 进入目录；普通单击选择检出目标。
- 登录窗口显示服务器、账号与密码，支持显示/隐藏密码。密码仍通过 stdin 传入 SVN，保留原有凭据作用域、单次重试及发布操作的认证预检。
- 新增界面文案已覆盖简体中文、繁体中文、英文、日文、韩文。深色主题继续使用主题变量。

## 与原型的区别

- 使用真实仓库数据、真实程序版本和系统窗口标题栏，不使用原型中的占位服务器、版本号或红黄绿窗口按钮。
- 修正版 fix1 已加入 macOS 钥匙串持久保存：仅在认证重试成功后保存，后续启动按服务器和账号读取。其他平台仍使用会话凭据。
- 不显示未实现的预计下载量、磁盘空间、证书有效性、服务器同步状态或文件增删行数汇总。差异面板中的行数来自实际差异。
- 检出目录使用逐级浏览，已有 SVN API 不支持的仓库 UUID、远端最近提交侧栏暂不展示。
- 仍使用现有统一差异视图；未新增并排差异与字符级高亮功能。

## 验证

- 前端生产构建与 106 项单元测试通过。
- 后端现有测试及新增参数校验测试通过；新增临时真实 SVN 仓库测试验证目录浏览、含空格、`&`、`@` 的路径及指定深度检出。
- 30 个认证 UI 场景覆盖 5 种语言、日志/检出及成功/取消/密码拒绝。
- `scripts/check-desktop-ui.cjs` 以隔离的虚构 IPC 数据验证生产前端的日志、差异、搜索、提交草稿传递、远程目录选择、检出参数、工作区选择器、密码可见性及窗口尺寸。
- 截图使用演示数据；安装包不包含演示数据或 mock 接口。

复现 UI 检查：先启动 `npm run preview -- --host 127.0.0.1 --port 1424`，再运行 `PLAYWRIGHT_CHANNEL=chrome npm run test:auth-ui` 和 `npm run test:desktop-ui`。需要 Chrome 或对应 Playwright 浏览器。

## 构建与安装

构建沿用 `docs/local-auth-fix.md` 中的工具链与内置 SVN 运行环境。此次 DMG 适用于 Apple Silicon 和 macOS 26 或更高版本，使用本地 ad-hoc 签名，未进行 Apple 公证。

退出当前 OrcaSVN，将新应用拖入 Applications 替换后重新启动。应用标识保持不变，工作区列表沿用已有设置；本次未自动替换用户安装的软件。

## fix1：工作区选择与记住密码

- 工作区弹窗使用独立的始终展开模式，不受旧侧栏折叠偏好影响；直接展示目录名和完整路径，点击即切换。收藏、排序和备注仍可使用。
- 登录成功后保存到 macOS 钥匙串，重启后自动恢复。同一服务器的明确账号分别保存，无账号 URL 使用最近一次成功登录的账号；协议、主机和端口隔离。
- 密码失效时进入原有认证弹窗，认证成功后更新保存值。保存失败会提示，但不会重复执行已经成功的 SVN 操作；不写入 localStorage、应用配置或 SVN 明文认证缓存。
- 106 项前端单元测试、89 项后端测试通过。另通过原生钥匙串跨进程读回测试：仅创建随机名称的虚构凭据，子进程读取后删除测试项，不读取用户已有凭据。
- 桌面回归以 `collapsed: true` 重现旧设置，验证首次打开直接显示目录、点击切换与重新加载后的列表展示。30 项认证 UI 场景验证成功才保存、取消和错误密码不保存。
- 安装包仍为 Apple Silicon / macOS 26+、ad-hoc 签名；升级后首次成功登录会建立钥匙串记录。如系统询问是否允许 OrcaSVN 访问该记录，请允许。

## fix2：历史文件对比与账号修改

- 修复历史文件列表隐藏“对比”按钮的问题；切换提交差异和版本区间会重新加载，切换文件保留版本区间。历史 URL 不提供无效的“工作副本 vs 基准”模式。
- 历史文件路径按段编码，支持中文、空格、`#`、`%`、`?`、`@` 等字符；删除文件使用前一版本作为 peg revision。
- 对比页随工作区初始化重新加载，退出或切换请求时忽略过期结果；明确展示没有差异、SVN 错误与二进制文件提示。
- 设置新增“SVN 账号 → 修改账号 / 密码”。显示当前服务器和应用管理的账号，不回传或回显已保存的密码。新密码通过 stdin 交给只读连接探测；使用临时 SVN 配置隔离旧认证缓存。探测失败保持旧账号，成功后更新会话及 macOS 钥匙串。
- 修改的是 OrcaSVN 使用的登录凭据，不会修改 SVN 服务器上的用户或密码。未在 URL 中指定账号的同服务器工作区共用默认账号；URL 中明确指定账号的工作副本仅允许更新该账号的密码，切换账号需使用新账号检出的工作副本。
- 验证：107 项前端单元测试、90 项后端测试通过；临时真实仓库测试覆盖特殊路径的历史修改、版本区间、删除和无差异；临时 svnserve 测试验证错误密码保持原账号、有效新账号可访问及显式账号隔离。
- 桌面回归、30 项认证 UI 场景，以及 `npm run test:diff-account-ui` 的对比模式/错误/空结果/二进制提示/账号替换检查通过。界面截图使用演示数据。
- Word、Excel、PDF 等二进制文件仍未实现文档内容比较，本次增加了清晰提示，不宣称支持这些格式的逐行文本比较。
